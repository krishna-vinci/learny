# Changelog

## v0.1.0

First open-source release of Studium, a self-hosted learning app with plain-file
study trees and a phone-friendly interface.

- Import web pages, papers, PDFs, EPUB/DOCX, Markdown and YouTube sources into a
  searchable library, with optional MinerU, Firecrawl, Exa and SearXNG integrations.
- Propose and edit course plans; draft cited chapters with independent fact-checking;
  refine notes with a tutor and preserve changes in git with undo/history.
- Review generated flashcards before Anki `.apkg` export; practice with quizzes,
  problems and teach-backs, and see weak topics on Today.
- Read math, source figures and credited images; explore sandboxed interactive
  visuals; compile course books with Pandoc/Typst.
- Choose models per agent role, use Pi subscription logins or provider API keys,
  and inspect background jobs, token usage and estimated costs.
- Manage admin-created accounts, SSO, separate user trees, encrypted integration
  secrets, backups, notifications and data exports.
- Use mobile navigation, reader themes/settings, PWA installation and offline
  reading. Self-host with Compose and GHCR images for amd64/arm64.
- AGPL-3.0-only licence, retained third-party notices, contribution/security guides,
  and automated CI and tagged image releases.
