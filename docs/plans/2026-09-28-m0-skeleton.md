**Goal:** A running Studium shell: log in, pick a study set, read notes (Markdown + math + mermaid + directives), chat with a Tutor agent that edits a note surgically; the note updates live, the change is a git commit, and the user can view its diff and revert it.

The Tutor runs in-process through the Pi SDK (`server/src/agent/` is the only importer of Pi) with four custom tools confined to the study root. Shared types and zod schemas live in `@studium/shared` (TS source, no build step).

## API contract (server ⇄ web; both sides build against this)

All JSON. Auth by cookie `studium_session` (or `Authorization: Bearer <STUDIUM_API_TOKEN>`). Every `/api/*` route except `/api/auth/login` returns `401 {"error":"unauthorized"}` without a valid session (unless no password is configured — then all requests are allowed as user `local`).

| Method & path | Request | Response |
|---|---|---|
| `POST /api/auth/login` | `{username, password}` | `204` + `Set-Cookie`; `401 {error}`; `429 {error}` |
| `POST /api/auth/logout` | — | `204`, cookie cleared |
| `GET /api/auth/me` | — | `200 {username}` / `401` |
| `GET /api/sets` | — | `200 SetSummary[]` |
| `GET /api/sets/:set/notes` | — | `200 NoteSummary[]` |
| `GET /api/sets/:set/file?path=<rel>` | path relative to the set | `200 FileView` / `404` |
| `GET /api/sets/:set/history?path=<rel>&limit=50` | path optional | `200 CommitInfo[]` (newest first) |
| `GET /api/sets/:set/diff?sha=<sha>&path=<rel>` | path optional | `200 {diff: string}` (unified) |
| `POST /api/sets/:set/revert` | `{sha}` | `200 {sha}` new commit / `409 {error}` on conflict |
| `GET /api/sets/:set/chats` | — | `200 ChatSummary[]` (newest first) |
| `POST /api/sets/:set/chats` | — | `201 {id}` |
| `GET /api/sets/:set/chats/:id` | — | `200 {id, messages: ChatMessage[], running: boolean}` |
| `POST /api/sets/:set/chats/:id/messages` | `{text, anchor?: string}` (anchor = open note path, set-relative) | `202` / `409 {error:"busy"}` |
| `POST /api/sets/:set/chats/:id/abort` | — | `204` |
| `GET /api/events` | — | SSE; each message `event: studium`, `data: StudiumEvent` JSON |

Types (exact, in `shared/src/api.ts`, Task 2):

```ts
export interface SetSummary { slug: string; title: string; status: "draft" | "active" | "paused" | "done"; level: number | null; deadline: string | null; nextAction: string | null }
export interface NoteSummary { path: string; title: string; order: number | null; status: "draft" | "checked" | "accepted" | null }
export interface FileView { path: string; frontmatter: Record<string, unknown>; body: string }
export interface CommitInfo { sha: string; date: string; author: string; subject: string }
export interface ChatSummary { id: string; title: string; created: string; modified: string; messageCount: number }
export interface ToolCallView { toolCallId: string; name: string; args: Record<string, unknown>; isError?: boolean; summary?: string }
export interface ChatMessage { id: string; role: "user" | "assistant"; text: string; tools: ToolCallView[]; timestamp: string }
export type ChatStreamEvent =
  | { kind: "text_delta"; delta: string }
  | { kind: "tool_start"; toolCallId: string; name: string; args: Record<string, unknown> }
  | { kind: "tool_end"; toolCallId: string; name: string; isError: boolean; summary: string }
  | { kind: "message_end"; message: ChatMessage }
  | { kind: "settled"; commitSha: string | null }
  | { kind: "error"; message: string };
export type StudiumEvent =
  | { type: "file"; set: string | null; path: string; change: "add" | "change" | "unlink" }
  | { type: "commit"; sha: string; subject: string; author: string }
  | { type: "chat"; set: string; chatId: string; event: ChatStreamEvent };
```

`file.path` is relative to the study root; `set` is its first segment when that is a set slug, else `null`.
