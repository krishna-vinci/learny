## Screens

### 1. Plan a set with the agent
- **API:** `POST /api/jobs {kind:"plan-set", set, goal, level?: 1-5, deadline?: "YYYY-MM-DD", sources?: string[]}` → 202 `{jobId, set}`. It creates the set if it doesn't exist. Server: `server/src/jobs/routes.ts`, `server/src/jobs/plan-job.ts`.
- **UI:**
  - In `web/src/components/NewSetDialog.tsx`, add an option "Let the agent plan it": goal (required), level 1–5, deadline, and optional library sources (reuse the source picker from `web/src/components/NewChapterSheet.tsx`).
  - Submit starts the job, closes the dialog and navigates to the new set. The existing activity indicator and toasts show progress.
  - Also add a "Plan with agent" action on the set home (`web/src/pages/SetHomePage.tsx`) for existing sets. It replans with the set's current `PLAN.md` goal prefilled.

### 2. Plan review in the Inbox
- **API** (server `server/src/routes/inbox.ts`, parser `server/src/inbox/plans.ts`):
  - the inbox list returns items with `kind: "chapter" | "plan"`
  - `GET /api/sets/:set/plan-proposals/:file` → `{plan, curriculum, sourcesToAdd}`
  - `POST …/:file/approve {draftFirst: 0-5 (default 3)}` → `{sha, jobIds}`
  - `POST …/:file/discard`
- **UI** (`web/src/pages/InboxPage.tsx`, 224 lines):
  - plan items get their own badge and icon
  - opening one shows the proposed PLAN (goal, scope, level, deadline), the curriculum as a numbered chapter list with prerequisites, and "Sources to add" as links, each with an "Add to library" button that uses the existing add-source flow
  - actions: **Approve & draft first N** (a stepper 0–5, default 3) and **Discard** (confirm)
  - after approving, toast and navigate to the set home

### 3. Book PDF
- **API:**
  - `POST /api/jobs {kind:"compile-book", set}`
  - `HEAD /api/sets/:set/book.pdf` → 200 with `last-modified` when a book exists, otherwise 404
  - `GET` the same URL downloads it
- **UI:**
  - On the set home, a "Book" card: "Build book (PDF)" or "Rebuild", plus "Download" (and the last-built time) when it exists.
  - Show progress while the job runs (the job event carries `progress`).
  - On `done`, the download becomes available. A toast "Book ready — Download" is added to `web/src/components/Activity/JobToasts.tsx`.

### 4. Import a documentation site
- **API** (server `server/src/routes/library.ts`):
  - `POST /api/library/site-map {url, search?, limit?}` → `{pages:[{url,title?,description?}]}`; 400 when Firecrawl isn't configured
  - `POST /api/library/site-import {urls: string[] (1–100), set?}` → `{queued, skipped:[{url,reason}]}`
- **UI** (`web/src/components/Library/AddSourceSheet.tsx`, 283 lines): a new tab "Docs site".
  1. A URL field plus an optional filter → **Find pages**.
  2. A list with checkboxes, a filter box, "select all / none", a count (cap 100 with a warning) and the page title or URL path.
  3. **Import N pages**, with an optional "Also link to set X".
  4. A result summary: queued, and skipped with reasons.

  Imported pages then appear through the existing ingest jobs and activity UI.

### 5. Suggested jobs in chat survive reloads
- **API** (server `server/src/agent/routes.ts`):
  - `GET /api/sets/:set/chats/:id/proposals` → `{proposals:[…]}`, the same shape as the live `job_proposal` stream event
  - `DELETE …/proposals/:proposalId` → dismiss
- **UI:**
  - On chat load/switch in `web/src/components/ChatDock/useChatDock.ts` (with `reducer.ts`), fetch the proposals and merge them into the reducer's proposal cards (dedupe by `proposalId`).
  - Dismiss calls `DELETE`. Running a proposal needs no extra call; it disappears on the next fetch.

### 6. Set-only revert
- **API:** `POST /api/sets/:set/revert {sha}` returns **409** `{error:"commit touches paths outside this set", paths}` when the commit touches other sets; retry with `{sha, scope:"set"}` to revert only this set's files.
- **UI** (`web/src/components/NoteHistory/NoteHistory.tsx`): on that 409, show a confirm dialog listing the outside paths. Explain that only this set's files will be restored and any later edits to them are overwritten. Confirm retries with `scope: "set"`.
