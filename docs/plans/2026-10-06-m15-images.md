# M15 — Real images in chapters (licensed, credited)

**Goal:** chapters show real images where seeing the real thing teaches — monuments, artefacts, materials, organisms, instruments, historical photos, source diagrams — legally and with credit. SVGs stay the tool for schematic diagrams (keep how they're made today).

## Evidence (live data, 2026-10-06)
- 98 source figures saved locally (M14), but **0 raster images embedded** in any chapter; agents redraw everything as SVG.
- Licences of saved figures: unknown 71, public domain 9, CC BY (2.0/3.0/4.0) 11, CC BY-SA 7. Most "unknown" are LibreTexts pages, which do carry CC licences on each page; detection misses them. Even the 27 reusable figures were redrawn — nothing tells the drafter to prefer a real image.
- No direct image search exists; images come only incidentally from source pages (and Exa `extras.imageLinks`, parsed but unused).

## Owner decisions
- **NC allowed:** this is a personal, non-commercial study app. CC BY-NC and CC BY-NC-SA images may be embedded with credit, controlled by an instance setting `media.allowNonCommercial` (default **true**, documented in `docs/DEPLOY.md`). ND licences: embed only unmodified (no crops/edits). Unknown or all-rights-reserved → link to the source or redraw as SVG; never embed.
- SVG generation stays as is.

## Work
1. **Licence detection** (`server/src/ingest/figures.ts` and friends): read LibreTexts' per-page licence (page tags/meta), Wikimedia Commons file licence via the Commons API (`extmetadata` LicenseShortName/Artist/Credit), OpenStax site-wide CC BY 4.0, Wikipedia-hosted images via Commons, `rel=license`/schema.org `license` generally. Re-run on a temp copy of the live library: report unknown → known counts.
2. **Image search** (new backend in `server/src/search/`, env-gated where keys are needed, all via `safeFetch`): Wikimedia Commons (API, no key), Openverse (`api.openverse.org`, anonymous; optional key env), The Met Collection API (public domain, no key), NASA Image and Video Library (no key), Smithsonian Open Access (optional `api.data.gov` key). Return {url, thumbnail, title, creator, licence, licence URL, source page, width, height}. Rank by relevance to the concept (title/description/tags; Jev `sources.rank`-style decision or LLM fallback), licence acceptability, resolution (≥ 800 px wide preferred), and subject fit. Exa `imageLinks` from good pages join as candidates (licence from their page).
3. **Plan + brief:** stage-1 planning adds 1–3 **image slots** per chapter where a real image teaches (with what it should show); stage-2 brief fills them from (a) permissive captured source figures, (b) image search, choosing the best licensed candidate; records the choice + credit. Brief stays lean (≤ ~5 KB).
4. **Save + embed:** download chosen images through `save_asset` (size/type limits, sidecar with licence, creator, source URL, licence URL), embed in the chapter as `![alt](../assets/x.jpg "Credit: Creator, Licence, Source")` (or the existing figure syntax if one exists) right where the concept is taught, with a learner-facing caption. Reader shows the credit under the image; the book prints it.
5. **Checker:** every embedded raster image has a sidecar with an acceptable licence (per the setting) and a visible credit; ND images unmodified; unknown/restricted embedded → blocker. Planned image slot missing without reason → blocker (same rule as visuals).
6. **Skills/docs:** `media-authoring` (when a photo beats a diagram; how to credit), `plan-set`, `draft-chapter`; D37 in `docs/decisions/LOG.md`; `docs/STUDY_TREE.md` sidecar fields.
