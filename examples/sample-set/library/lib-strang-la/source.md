# Introduction to Linear Algebra — summary

A classic introductory text that moves from vectors and linear combinations through
elimination, vector spaces, and eigenvalues, ending with the singular value
decomposition. The emphasis throughout is geometric: what each operation does to
space, and why the pieces fit together the way they do.
