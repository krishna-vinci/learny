## Goal

Build enough linear-algebra intuition to follow modern ML papers: vectors, matrices,
eigenvalues, and the singular value decomposition, with hands-on NumPy practice.

## Scope — in

- Vectors, bases, and linear independence
- Matrix multiplication, elimination, and rank
- Eigenvalues, eigenvectors, and the SVD

## Scope — out

- Measure theory and functional analysis
- Numerically stable solver implementation details
