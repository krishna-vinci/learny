# D3 7.9.0 (bundled browser global)

Declare `libs:["d3"]`. For scales/shapes only, prefer a built-in widget.

```js
const x=d3.scaleLinear().domain([-2,2]).range([60,580]);
const y=d3.scaleLinear().domain([-2,2]).range([340,40]);
const points=d3.range(101).map(i=>{const v=-2+i*0.04;return [x(v),y(Math.sin(v))]});
const path=d3.line()(points);
const ticks=x.ticks(5);
```

Needed APIs: scaleLinear/domain/range/clamp/ticks/invert, scaleBand/padding,
line/defined/x/y, curveLinear, range, min/max/extent, interpolateNumber,
select/append/attr/text (DOM inside the frame only). Update synchronously inside
studium.mount draw. No transitions/timers/private animation loop, no d3.json/csv/
fetch/remote data. Use theme and studium.palette; reserve room for axis units.
