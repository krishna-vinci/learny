# p5 2.3.4 (bundled browser global)

Declare `libs:["p5"]`. Use instance mode, noLoop, and runtime-owned draws:

```js
let sketch, frame = {state:{},theme:{}};
document.addEventListener('DOMContentLoaded',()=>{
  sketch = new p5(p=>{
    p.setup=()=>{ const el=document.getElementById('studium-stage');p.createCanvas(el.clientWidth,el.clientHeight);p.noLoop(); };
    p.draw=()=>{p.background(frame.theme.bg||'#fafaf9');p.stroke(studium.palette[0]);p.line(40,80,160*(frame.state.scale||1),80);};
    p.windowResized=()=>{const el=document.getElementById('studium-stage');p.resizeCanvas(el.clientWidth,el.clientHeight);};
  }, document.getElementById('studium-stage'));
});
studium.mount({scenes:[{state:{scale:1},narration:'One unit.'},{state:{scale:2},narration:'Twice as long.'}],draw:f=>{frame=f;sketch?.redraw();}});
```

Needed APIs: createCanvas, resizeCanvas, noLoop, redraw, background, stroke, fill,
noFill, strokeWeight, line, circle, rect, beginShape/vertex/endShape, push/pop,
translate/rotate/scale, text/textSize/textAlign, mouse/touch callbacks, remove.
No loadImage/loadFont/loadJSON/fetch. No global auto-loop. Label units; keep the
static SVG poster independent of the canvas. Context7: p5 reference noLoop/redraw.
