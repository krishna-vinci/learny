# Subject ideas

Pick one example relevant to the section and its sources. These are ideas, not
requirements to decorate every chapter. The template filenames are in `templates/`.

| Subject guide | Idea → template |
| --- | --- |
| math | Slope as a parameter → function-plot.json; basis-vector stretch → matrix-transform.json; rotate/scale/rotate SVD → matrix-transform.json with svd |
| science | Damped displacement vs time → function-plot.json; labelled repeat-unit counting → svg-labelled-diagram.html; stages of a reaction pathway → step-through.json |
| technology | One sorting pass → step-through.json; a cache-miss trace → step-through.json; queue throughput sample → Vega-Lite in media-authoring |
| history | Sourced milestones → timeline.json; overlapping eras → timeline.json; a site's changing spatial role → svg-story.html |
| finance | Hypothetical simple vs compound growth → function-plot.json; correlation and portfolio variance → function-plot.json; expense categories with sourced units → Vega-Lite |
| language | Subject/verb roles in one sentence → step-through.json; active-to-passive transformation → step-through.json; compare two phrase attachments → svg-story.html |
| practical | Assembly/check sequence → step-through.json; measured electricity use → Vega-Lite; effect of moving a labelled mechanical part → svg-labelled-diagram.html |

Continuous motion should explain a mechanism: e.g. a particle's projected
oscillation → p5-animation.html. Custom hover/selection on data can start from
d3-chart.html only when Vega-Lite and the widgets cannot provide it. Personal
reflection, definitions already clear in prose, and decorative metaphors need none.
